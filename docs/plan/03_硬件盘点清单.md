**先数清楚：一共几个舵机？**

- 6 个（5 关节 + 夹爪）→ 走 00 文档 §4.4 的 **A 方案**（可做 yaw 控制）
- 5 个（4 关节 + 夹爪）→ 走 **B 方案**（无 yaw，只能抓对称物体）

结论：☑ **A 方案**（2026-11-10 已确认：6 个舵机 = 5 关节 + 夹爪）

J5 已确认：**绕工具轴自转（roll）** → `J5 = yaw − J1`，夹爪朝向可控。P1 只需补测它的**零位角**（夹爪开口朝 +x 时记为 0°），写进 `docs/dh_table.md`。

## 3. 电源

| 项 | 值 | 怎么查 |
|---|---|---|
| 铭牌电压 | 7.5v | 拍照 |
| 铭牌电流 | 待测 | 拍照 |
| 实际空载电压（万用表） | 7.5v | 量 |
| 实际带载电压（接 1 个舵机堵转时） | 待测 | 量，看跌多少 |
| 预估 5 舵机峰值电流 | 待测 | 单舵机堵转电流 × 5 × 0.6（不是全堵转，取经验系数） |
| 是否够用 | 待测 | 对比 |

**判定：** 峰值需求 > 电源额定 × 1.5 → 危险，必须加电容 + 限速 + 分时动作，或换电源。

**必做：** 在 ZLink 电源输入端并 1000–2200 µF 电解电容（注意极性）。成本 5–10 元，能救你很多次「莫名其妙复位」。

## 4. STM32 与串口

| 项 | 值 |
|---|---|
| 型号（如 STM32F103C8T6） | c8t6 |
| 板子来源（最小系统板/开发板） | 最小开发板 |
| 可用 UART 数量 | 3 个 USART；计划 USART2 接 ZLink，USART1 调试，USART3 备用 |
| 与 PC 连接的 USB 转串口芯片 | DAPLink（SWD；虚拟串口待确认） |
| 与 ZLink 连接的串口 | PA2/PA3（USART2） |
| 供电方式（USB 供电 / 外部 5V / 3.3V LDO） | 5.5v串口供电 |
| 是否与 ZLink 共地 | 是 |
| 下载方式（ST-Link / 串口 ISP） | daplink |

⚠️ **常见坑**：STM32 用 USB 供电、舵机用另一个电源，两个电源不共地 → 串口通信乱码/丢包。**必须共地。**

## 8. 上电前 10 项检查（P2 每次上电前过一遍）

1. ⬜ 电源电压 = 舵机额定（万用表实测）
2. ⬜ 电源电流 ≥ 峰值需求 / 1.5
3. ⬜ STM32、ZLink、电源三者共地
4. ⬜ 舵机线无短路（通断档）
5. ⬜ 底座固定，桌面不晃
6. ⬜ 运动范围内无手、线、杂物
7. ⬜ 软限位已写入固件
8. ⬜ 物理急停手段就位（开关/插头）
9. ⬜ 首次速度 ≤ 30%
10. ⬜ 有人在场
