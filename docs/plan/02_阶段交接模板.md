# 阶段交接模板

> 用法：每完成一个阶段，开新对话，把下面「开场消息」复制进去，改掉填不出来的部分，附上三个文件。
> 这个文件同时给未来的 AI 一份**评估协议**，保证每次换对话，考核标准都一样。

## 二、给未来 AI 的评估协议（复制进对话，或让 AI 读这份文件）

> 如果 AI 想直接进入下一阶段，用这段拦住它。

### 评估三关

**第一关：口述关（20 分钟）**
从下面「问题库」随机抽 5 题，要求用户**不看资料**回答。每题按 0–2 分：
- 0 = 说不清或背术语
- 1 = 说对大意，缺细节
- 2 = 能讲清原理 + 举自己的例子
总分 < 6/10 → 不通过。

**第二关：证据关（10 分钟）**
检查台账里的验收项：
- 每条是否有可验证证据（数值 / 文件 / 视频 / commit）？
- 数值是否合理（比如「IK 误差 0.001 mm」大概率是假的）？
- 有没有「只跑通一次就写成功」的情况？
发现 ≥ 2 条证据缺失或不可信 → 不通过。

**第三关：迁移关（20 分钟）**
改一个条件，让用户现场推演或改代码：
- 例：「如果 J4 的零点偏了 3°，你的 IK 会怎么错？怎么验证？」
- 例：「把物体放到 r=10 cm，会发生什么？为什么？」
- 例：「标定板换成 A3 打印但方格实际是 19.5 mm，误差多大？」
答不出但能说出「我会怎么查」→ 1 分；完全没思路 → 0 分。

### 结论规则

| 情况 | 结论 |
|---|---|
| 三关都过 | ✅ 通过，进入下一阶段 |
| 口述/迁移 < 6 分，证据齐 | 🟡 补课：列 3–5 个具体补课项 + 工时，1 周内补完再考 |
| 证据缺失 ≥ 2 条 | 🟡 补证据：重做验收，不接受「我记得做过」 |
| 基础概念错（如坐标系方向、AX=XB 含义） | 🟥 降级：回到上一阶段对应周，重做 |

### 禁止事项

- 禁止因为「用户说学会了」就通过。
- 禁止一次给四周任务；只给下一周，且每周有验收。
- 禁止生成完整可运行代码让用户直接跑；核心算法只给伪代码和检查点。
- 讲解必须中文，术语保留英文。

## 三、问题库（按阶段）

> 未来 AI 从这里抽题；用户也可以自己拿来自测。

### P0 地基

1. 齐次变换矩阵的逆怎么求？为什么不是直接对 4×4 求逆？
2. `T_0_3 = T_0_1·T_1_2·T_2_3`，如果改成右乘（`T_0_1·T_1_2` 变成在末端系变换），几何意义变了吗？
3. ZED 的相机坐标系 x/y/z 分别指向哪？你怎么验证的？
4. 你的舵机总数是多少？如果是 5 个，说明缺了什么自由度？
5. 电源电流不够会出现什么现象？你怎么测？
6. 为什么 P0 不接线通电？
7. `pytest` 里你写了哪三个测试？每个在防什么错？
8. 欧拉角和四元数各适合什么场景？

### P1 测绘 + 仿真 + 运动学

1. 你的 DH 表每一行的 a/alpha/d/theta 分别对应哪个物理尺寸？拿卡尺量的哪个位置？
2. 标准 DH 和改进 DH 的区别？你用哪种，为什么？
3. 正运动学怎么算？给我 J1 转 30°、J2 转 40° 时末端大概在哪。
4. 你的逆解为什么能写成解析式？5 自由度怎么处理姿态？
5. 肘上/肘下两解怎么选？选错会怎样？
6. 什么是奇异位形？你的臂在哪里会奇异？怎么避免？
7. 梯形速度曲线为什么比直接插值好？加速度不连续会怎样？
8. IK 100 点成功率 93%，剩下 7 点为什么失败？分布在哪？
9. 你的 FK 和 PyBullet 误差 0.4 mm，这个误差来自哪？
10. 库的 IK 和你自己推的解析解差在哪？什么情况下你会切到库？
11. 你的 URDF 里第 3 个 joint 的 origin 和 DH 表第 3 行是什么关系？

### P2 真机链路

1. 你的串口协议长什么样？怎么处理粘包/半包？
2. 软限位为什么在 STM32 做而不是上位机做？两边都做有意义吗？
3. 越界指令你选择「拒绝」还是「clamp」？为什么？
4. 超时 500 ms 怎么定的？太短/太长分别有什么问题？
5. 舵机一动 STM32 就复位，你怎么排查？（提示：分层）
6. 共地不良的表现是什么？怎么用万用表确认？
7. 堵转检测怎么做？阈值怎么定？
8. 你的 servo=k·q+b 是怎么标定的？两个点够吗？误差多大？
9. 急停用硬件还是软件？为什么？

### P3 ZED + 手眼标定

1. AX=XB 里 A/B/X 各是什么？为什么至少 3 组，且要非共面？
2. 为什么旋转误差会放大平移误差？举个数。
3. 你用哪种手眼算法？残差多少？为什么选它？
4. 标定板不平会怎样？你怎么检查平整度？
5. 采点时为什么「从同一方向接近」？这解决的是什么误差？
6. ZED 的深度误差在你工作距离上大概多少？怎么测的？
7. 手眼矩阵怎么验证？触碰误差 14 mm，主要来自哪三项？
8. `solvePnP` 的输入输出是什么？相机内参从哪来？
9. 如果相机被碰了一下，你怎么快速判断标定是否还有效？

### P4 静态抓取

### P6 求职

## 四、附件与路径约定

每次交接至少带：

- `00_总纲与学习计划.md`
- `01_进度台账.md`
- 代码仓库链接（或本地绝对路径）
- 阶段验收的证据：视频链接 / CSV / 图片 / commit hash

**不要做的：**
- 不要把整个代码库贴进对话（用路径 + 关键片段）。
- 不要只说「我学完了 P2」，要说「P2 的 7 条验收我过了 6 条，第 5 条差 3 mm」。
- 不要说「代码在本地」，至少推一个 tag；否则 AI 只能靠你口述，评估会失准。
- 不要在台账没更新时开新对话——那样 AI 只能重新问你一遍，浪费一轮。
