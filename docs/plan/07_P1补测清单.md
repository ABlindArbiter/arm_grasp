**测量方法：**

1. 手动把关节转到机械下限（不要硬掰，遇到明显阻力就停）。
2. 手机水平仪贴在父连杆，读绝对角；再贴子连杆，读绝对角；两者相减 = 关节角。
3. `0° = 该关节机械下限`；上限同理。
4. 上下限各拍一张，画面里能看到水平仪读数和关节。
5. 如果 J1/J3 的“连杆角”超过 240°，同时记 ZLink 的舵机角（若能只读上电）；两者比值就是减速比。没有减速比就重测。

## 6. 判定规则（避免又出现“数据可疑”）

- **J1/J3 超过 240°**：如果量的是连杆角、舵机是 240°，记录“servo 角 vs 连杆角”的换算/减速比；没有减速比就重测。
- **d1**：以“八角台面 → J2 = 23”为准；如果原点在桌面，`d1` 应加 `h0`；两者选一个写死，不要混。
- **限位精度**：手机水平仪 ±3–5° 正常；软限位留 5–10° 余量，不要把软限位设到物理极限。
- **J5 零位**：物理标记必须拍；ZLink 读数没有就写“待 P2”，不要编一个数。
- **照片**：每个数至少一张；没有照片的数按“未测”处理（沿用台账规则）。
