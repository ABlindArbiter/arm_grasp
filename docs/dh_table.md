# DH 表（P1-W3 第一版）

> 单位：mm；角度：度。采用标准 DH。
> 约定：`T_ab` 把 b 系的点变到 a 系，`p_a = T_ab @ p_b`。
> 基座系：原点 `O` 在底座回转中心与桌面交点，`+z` 向上，`+x` 指向 J1=0 时臂的正前方。
> 状态：长度和限位是实测值；`alpha`、`theta_offset` 是初稿假设，W4/W5 用 URDF/FK 校验。

## 1. 轴线示意

```text
z / J1
↑
|
|                    [1] 夹爪 / TCP
|                     |
|                 ↻ [2] J5（绕工具轴）
|                     |
|                  [3] J4 ⊗
|                 /
|           L3  /
|              [4] J3 ⊗
|             /
|       L2  /
|         [5] J2 ⊗
|          |
|    d1    |
O──────────┴────────→ x
```

- `[ ]` 内是舵机 ID，不是 DH 关节号。
- J2/J3/J4 三轴平行，方向垂直纸面；J1 竖直；J5 沿工具轴。
- `⊗` 表示轴指向纸里；正方向待 P2 用舵机方向确认。

## 2. 关节表

| DH i | 关节 | 舵机 ID | 类型 | 轴线 | 0° 定义 | 下限 | 上限 |
|---|---|---|---|---|---|---|---|
| 1 | J1 | 6 | yaw | 竖直 | 下限（暂定与 +x 重合） | 0° | 300° |
| 2 | J2 | 5 | pitch | 水平，∥ J3/J4 | 下限 | 0° | 180° |
| 3 | J3 | 4 | pitch | 水平，∥ J2/J4 | 下限 | 0° | 270° |
| 4 | J4 | 3 | pitch | 水平，∥ J2/J3 | 下限 | 0° | 240° |

> DH 的 J1–J5 从底座到末端排；舵机 ID 是 `6→5→4→3→2`，夹爪是 `1`。

## 4. 轴线关系

- J1 竖直；J2/J3/J4 水平且互相平行。
- J2 在 J1 轴线上，`a1=0`，高度 `d1=23 mm`。
- J4 与 J5 约 90°；J5 沿工具轴，是 roll。
- J5 的自转不改变连杆长度；`L4` 是从 J4 到 TCP 的固定偏移。
- J2/J3/J4 的物理限位已按父子连杆夹角实测，0° 取各自下限。

## 6. 变换链

```text
T_0_tool(q) =
  Rz(q1) · Tz(23) · Rx(-90°) ·
  Rz(q2) · Tx(100) ·
  Rz(q3) · Tx(98) ·
  Rz(q4) · Rx(+90°) ·
  Rz(q5) · Tz(135)
```

其中 `q1…q5` 是 DH 关节角，不是舵机 ID。

## 7. 待确认
